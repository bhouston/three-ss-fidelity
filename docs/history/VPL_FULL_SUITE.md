# Experimental VPL full-suite captures

The experimental `three-new-vpl-shadow-maps` renderer is enabled in `registry.json` and
the fidelity viewer configuration. All 55 registered scenes were captured through
the standard fidelity CLI, using each scene's dimensions, 64 frames, and seed 1.
Existing renderers and captures are unchanged.

The run used source commit `033f942a8ac4f9092d62e209ae001a5e210aab72`, Node 26.10.0,
Chrome 154.0.8037.98, Windows, and an RTX 3060 Ti host (driver 32.0.16.1714).
The renderer retains its default 128 VPLs, 8 bounce limit, 16 candidate multiplier,
64-pixel shadow faces, and minimum distance 3. These are fidelity captures, not a
performance benchmark.

```powershell
pnpm --filter @three-fidelity/playground dev --host 127.0.0.1 --port 5193 --strictPort
pnpm render --renderer three-new-vpl-shadow-maps --root-url http://127.0.0.1:5193/ --executable-path 'C:/Program Files/Google/Chrome/Application/chrome.exe' --chrome-arg=--enable-unsafe-webgpu
pnpm exec fidelity-kit process fidelity-results
pnpm site:build
```

All 55 captures have the registered dimensions. The sealed `gi-probe-thick-wall`
control is entirely black, matching both committed reference images. For this
zero-error pair, the processor serializes infinite PSNR as `null`; it is excluded
from the finite-value summaries below.

The standard processor's metrics give median PSNR of 25.86 dB against Blender and
25.57 dB against the GPU path tracer across the other 54 scenes. Finite results
range from 5.54 to 49.97 dB against Blender and 7.04 to 44.65 dB against the GPU
path tracer. The experimental label remains: the run records fidelity differences
and does not claim parity with the older VPL renderer.

[The capture manifest](vpl-full-suite.json) records dimensions, frames, SHA-256
hashes, and PSNR values from the standard processor. Captures are committed under
`fidelity-results/<scene>/beauty/three-new-vpl-shadow-maps.avif`. Metrics, difference
images, and the viewer index are regenerated by the normal suite commands.

Validation passed: build, types, lint, 261 tests with coverage, fidelity processing,
website generation, and the unified browser contracts. Dependency audit reported
the same seven existing advisories; dependencies were not changed.
