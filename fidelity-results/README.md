Explore the rendering quality and speed of **three.js screen-space effects**, including global illumination (SSGI), reflections (SSR), ambient occlusion (AO), and temporal anti-aliasing (TRAA).

The fidelity suite compares browser renders against path-traced reference images. Inspect image differences and PSNR to understand where each renderer succeeds and where it needs improvement.

Performance measurements show frame rate, setup stages, responsiveness, and optional convergence for selected renderer/scene pairs on each benchmark machine.

Try the same scenes and renderers in **Live**, move the camera, and watch frame rate and setup measurements as they run. Renderer settings and scene definitions are shared across all three sections.
