This viewer benchmarks [three.js](https://threejs.org/) real-time renderers. Inspect frame times, startup cost, GPU timing, and stability across Three-Base, Three-New, and the light bake, light probe, DDGI, SSR, and SSGI variants.

The current benchmark uses the Cornell box with a metallic sphere: **26 configurations, each run once**, recorded on an Apple M3 at 1920 × 1080 with vsync disabled. Each configuration saves compact metrics directly and captures its AVIF screenshot after the measured run. Measurement includes the first ready frames, without warmup. The viewer defaults to fastest average rendering first (highest average FPS / lowest average frame time), shares a time scale across visible timelines and combines setup phases, watchdog lateness, and frame timing in one graph. All chart axes begin at example navigation. The renderer initializes automatically on page load, including HTML and JavaScript loading in the first `load` phase. Uncovered initialization time is inferred as `unknown` blocks. Open an entry for the same combined timeline with CPU/GPU selection, focused histograms, bandwidth, and measured init phase totals.

Read the [benchmark notes](https://github.com/bhouston/three-ss-fidelity/blob/main/docs/history/performance/METALLIC-CORNELL.md) for historical measurements and reproduction context. The [fidelity viewer](https://ss-fidelity.ben3d.ca/) shows the corresponding image quality comparisons.

These results were refreshed on October 4, 2026 using the navigation-based, automatic-start benchmark. Exact browser, host, toolkit and timing metadata are recorded in each metrics file. The older warmup-based measurements in the historical notes describe a different measurement window.
